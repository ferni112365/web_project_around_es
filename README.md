Nombre del proyecto: ## Tripleten web_project_around_es
Descripción del proyecto: sitio web dinámico que nos muestra diferentes lugares de Estados Unidos. En esta página, el usuario puede editar su perfil y agregar más lugares interesantes: estos también pueden ser eliminados o resaltarlos como lugares favoritos.
Autor: Fernando Hernandez Barrios.
Tecnologías utilizadas: HTML5, CSS, metodología BEM y JavaScipt.
